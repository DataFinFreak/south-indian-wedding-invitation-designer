South Indian Wedding Invitation Designer

An open-source Agent Skill that helps an AI assistant design animated, mobile-first South Indian wedding e-invites to share as a link on WhatsApp.

View the skill on GitHub

What the skill ships

One reusable template with six presets, shown here with a fictional couple and venue.

Template sample

Fictional couple, Mysuru Aramane preset. Add ?preset=temple-kolam to try another look.

Real invitations

The author’s own wedding invitations, shared with permission. Hand-built designs that inspired the skill; the couple photo is left out. Tap the cover on each page to open it. Best on a phone.
